Nearby Alert - Fabric 1.21.4 (Java 21)

BUDOWANIE:
1. Pobierz szablon Fabric (https://github.com/FabricMC/fabric-example-mod, branch 1.21.4)
   albo uzyj IntelliJ -> Minecraft Development plugin.
2. Skopiuj do niego: src/ , build.gradle , gradle.properties (nadpisz).
   (folder gradle/ i gradlew bierzesz z szablonu)
3. Uruchom: ./gradlew build   (Windows: gradlew.bat build)
4. Gotowy mod: build/libs/nearbyalert-1.0.0.jar -> do folderu mods (wymaga Fabric API).

UZYCIE: klawisz K = menu (suwak zasiegu 1-128 kratek, wl/wyl powiadomien, wl/wyl dzwieku).
Klawisz mozna zmienic w Ustawienia -> Sterowanie.
